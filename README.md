## Overview

<overview>
Gōlem is an automated machine learning framework that accelerates scientific discovery by efficiently exploring complex design possibilities. It empowers researchers and developers to optimize structures and models across diverse fields, from graph analysis to molecule design, without manual intervention.
</overview>

## Core features

<corefeatures>

1. **Automated Machine Learning**: Framework for automating machine learning workflows and discovery.
2. **Graph Optimization**: Optimizes structures represented as directed acyclic graphs (DAGs).
3. **Adaptive Optimization**: Uses multi-armed bandits for intelligent resource allocation.
4. **Modular Adapter System**: Integrates with graph libraries like NetworkX easily.
5. **Visualization Tools**: Provides tools to analyze optimization histories and evolved structures.

</corefeatures>

## Installation

Install GOLEM using one of the following methods:

**Build from source:**

1. Clone the GOLEM repository:
```sh
❯ git clone https://github.com/andreygetmanov/GOLEM
```

2. Navigate to the project directory:
```sh
❯ cd GOLEM
```

3. Install the project dependencies:


**Using `pip`** &nbsp;
[<img align="center" src="https://img.shields.io/badge/Pip-3776AB.svg?style={badge_style}&logo=pypi&logoColor=white" />](https://pypi.org/project/pip/)

```sh
❯ pip install -r requirements.txt
```
